# 기가차드 5일차 · 처음 실행하는 사람을 위한 한 장 안내

**대상:** 포장본 `GIGACHAD-release-…`을 받은 Windows 사용자. 일반 사용자 권한으로 실행합니다. 관리자 권한·방화벽 변경·개인 인증 파일은 필요하지 않습니다.

## ① 준비와 실행

1. 받은 **포장 폴더 전체**를 보관합니다. ZIP이면 먼저 압축을 풉니다. 기존 프로젝트·제출물은 지우거나 옮기지 않습니다.
2. 폴더를 파일 탐색기로 열어 주소창에 `powershell`을 입력하고 Enter를 누릅니다. `node --version`을 실행합니다. **v24.19.0 권장, 22~24 지원**. 명령이 없다면 [Node.js 공식 사이트](https://nodejs.org/)의 설치 방법을 확인하고 새 PowerShell에서 다시 검사합니다.
3. 폴더 안의 **`GIGACHAD-launch.lnk`가 있으면** 더블클릭합니다. 없으면 **`GIGACHAD-start.cmd`**를 더블클릭합니다. `케셰브가 켜졌습니다`는 제공 시작 도구의 기존 이름이며, 앱을 기가차드라고 부릅니다.
4. 실행 창을 열어 둔 채 브라우저에서 **http://127.0.0.1:5189/** 를 엽니다.

## ② 화면 확인과 종료

- `보호 현황` 상단 네 카드: **CPU(%) · 메모리(GiB) · 디스크 남은 공간(GiB) · SDP 연결 상태**. 처음 세 값은 *앱 서버를 실행한 PC*에서 잰 값과 시각입니다. SDP는 별도 연결이며 기본 포장은 `SDP 미연결`일 수 있습니다.
- **PC 상태 다시 조회** 및 **Windows 상태 다시 조회**를 눌러 `조회 중` → 새 측정 시각 또는 `확인 불가`·이유·다음 행동을 확인합니다. Tab으로 이동하고 Enter/Space로 실행할 수 있습니다.
- `실제 측정`과 예제/모의 값은 다릅니다. 읽지 못한 값을 0으로 꾸미지 않습니다. Windows System·Application 경고·오류 건수는 **침해·공격 탐지 결과가 아닙니다**.
- 종료할 때 **실행 창에서 Ctrl+C**를 누릅니다. 브라우저만 닫아서는 종료되지 않습니다. 다시 실행하려면 ①의 3번부터 반복합니다.

## ③ 막힌 경우 (보안 설정을 바꾸지 마세요)

| 증상 | 다음 행동 |
|---|---|
| `node` 없음/버전 다름 | Node.js 22~24 확인 후 PowerShell 다시 열기 |
| 포트 5189 사용 중 | 포장 폴더 PowerShell에서 아래 명령으로 실행한 뒤 `http://127.0.0.1:5190/` 열기. 기존 프로그램을 종료하지 않기 |
| 앱 폴더/파일을 찾지 못함 | 압축을 풀었는지, 같은 폴더에 `src`·`tools`·`package.json`이 있는지 확인 |
| Windows 권한 거부/보안 경고/`확인 불가` | 관리자 권한으로 우회하거나 보안 기능을 끄지 않고 화면의 이유와 오류 문구 기록 |

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -Port 5190
```
