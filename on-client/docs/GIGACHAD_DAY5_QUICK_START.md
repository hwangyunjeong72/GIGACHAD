# 기가차드 5일차 · 처음 실행하는 사람을 위한 한 장 안내

**대상:** 0.2.21 소스의 `on-client` 폴더를 받은 Windows 사용자. 일반 권한으로 실행하며 방화벽·인증 설정을 바꾸지 않습니다. **이전 0.2.11의 `GIGACHAD-start.cmd` 단순 포장 안내는 최신 기본 포장에 적용되지 않습니다.**

## ① 준비와 실행

1. 받은 프로젝트의 **`on-client` 폴더**를 파일 탐색기로 엽니다. ZIP이면 먼저 압축을 풀고 기존 프로젝트·제출물은 지우거나 옮기지 않습니다.
2. 주소창에 `powershell`을 입력하고 Enter를 누릅니다. `node --version`을 실행합니다. **v24.19.0 권장, 22~24 지원**. 명령이 없다면 [Node.js 공식 사이트](https://nodejs.org/)의 설치 방법을 확인하고 새 PowerShell에서 다시 검사합니다.
3. 아래 실행 명령을 **`on-client` 폴더에서** 한 줄로 입력합니다. `케셰브가 켜졌습니다`는 제공 시작 도구의 기존 이름이며, 앱을 기가차드라고 부릅니다.
4. 실행 창을 열어 둔 채 브라우저에서 **http://127.0.0.1:5189/** 를 엽니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
```

## ② 화면 확인과 종료

- 기가차드 학생 **상단 네 카드**(CPU·메모리·디스크·SDP 별도 상태)에서는 **PC 요약 다시 조회**를 눌러 실제 측정 시각과 직전 두 번의 값을 비교합니다. SDP는 PC 조회로 판정하지 않고 **별도 확인 필요**로 남깁니다.
- 아래 0.2.21 **제공 내 PC 상태**에서는 **내 PC 확인**을 눌러 CPU·메모리·디스크·네트워크·Windows 방화벽·최근 이벤트를 읽습니다. 원하면 **10초마다 확인**을 직접 켭니다. Tab/Enter/Space로 버튼을 조작합니다.
- `실제 측정`과 예제/모의 값은 다릅니다. 읽지 못한 값을 0으로 꾸미지 않습니다. Windows System·Application 경고·오류 건수는 **침해·공격 탐지 결과가 아닙니다**.
- 종료할 때 **실행 창에서 Ctrl+C**를 누릅니다. 브라우저만 닫아서는 종료되지 않습니다. 다시 실행하려면 ①의 3번부터 반복합니다.

## ③ 막힌 경우 (보안 설정을 바꾸지 마세요)

| 증상 | 다음 행동 |
|---|---|
| `node` 없음/버전 다름 | Node.js 22~24 확인 후 PowerShell 다시 열기 |
| 포트 5189 사용 중 | `on-client` PowerShell에서 아래 명령으로 실행한 뒤 `http://127.0.0.1:5190/` 열기. 기존 프로그램을 종료하지 않기 |
| 앱 폴더/파일을 찾지 못함 | 압축을 풀었는지, 같은 폴더에 `src`·`tools`·`package.json`이 있는지 확인 |
| Windows 권한 거부/보안 경고/`확인 불가` | 관리자 권한으로 우회하거나 보안 기능을 끄지 않고 화면의 이유와 오류 문구 기록 |

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -Port 5190
```

- 마지막으로 성공한 단계(준비/실행/접속/재조회/종료·재실행): **미확인**
- 막힌 단계·오류 문구 원문·재시도 행동·결과: **아직 전달받지 못함**

비밀번호·토큰·개인 경로·IP·이벤트 원문은 캡처나 기록에서 제외합니다. **이 안내는 원문 확인을 바탕으로 작성했으며, 다른 사람의 독립 실행 성공 기록은 아닙니다.** 자세한 해결 방법은 [기존 실행 안내](STUDENT_LAUNCH_GUIDE.md)에 있습니다.
