## 2. 처음부터 끝까지 시연할 핵심 기능 3가지

시연 목표 시간은 약 6분이다. **아래는 시연 계획이며, 사용자 PC에서 연습·실행했다는 진술이 아니다.** 현장에서 실패하면 그 상태와 이유를 그대로 기록한다. 보안 설정 변경·관리자 권한 획득·침투 시험은 하지 않는다.

**2026-10-28 캡처 대조:** 사용자가 실행 화면 4장을 제공했다. 제공 PC 카드의 일부 수치는 관찰되지만, 이 세 순서를 처음부터 끝까지 같은 실행에서 완료한 증거는 아니다. 1번은 **제공 PC 화면만 부분 확인**, 2번은 **미확인**, 3번은 **Windows 기록을 제외하고 부분 확인**이다. 이미지 자체는 공개 저장소에 올리지 않고, 화면에 표시된 비밀이 아닌 요약만 아래 E01~E07에 기록한다.

**실행본 차이 확인 필요:** GitHub `main`의 학생 코드에는 상단 4카드와 렌더러가 있으나, 전달된 캡처에는 학생 상단 4카드가 없고 여러 학생 영역이 `학생 구현 대기`다. **화면을 연 실제 프로젝트 폴더에서** `git rev-parse HEAD`, `git status --short`를 확인하고, GitHub의 현재 커밋과 대조한다. 이 차이만으로 구버전 실행·파일 덮어쓰기·모듈 로딩 실패 중 원인을 확정할 수는 없다. 기존 작업 폴더를 초기화하거나 덮어쓰지 않는다.

캡처 원본은 이번 GitHub 커밋에 넣지 않았다. 나중에 추가 시 **직접 확인한 날짜·시간(KST), 출처(실제 로컬 PC/예제/모의), 관찰 결과, 오류 이유**를 대조한다. 캡처와 로그에 계정 토큰·비밀번호·인증 번호·개인 IP·이벤트 원문을 넣지 않는다.

## 4. 남아 있는 한계

1. **사용자 PC 화면 일부 확인, 학생 시연 미완료:** 제공 PC 상태 화면의 수치·시각은 캡처로 읽을 수 있다. 그러나 학생 상단 4카드·두 번 조회 추이·재시작은 확인하지 못했고, 캡처 실행본의 최종 Git SHA도 미확인이다.
2. **방화벽·이벤트 일부 확인:** 방화벽 세 프로필 `켜짐`은 화면으로 확인했다. Windows 기록은 `확인 불가`이며 이유·경고/오류 건수는 확인되지 않았다. 제공 조회는 System·Application 기록 **합산**이며 로그별 건수를 보증하지 않는다. 일부 집계 가능성(최대 5,000건)을 기록한다.
3. **SDP·AI·실제 보안 조치 구분:** 사용자 캡처에는 계정·AI 연결 및 모델 목록 `verified` 표시가 있으나, 이는 화면상 연결 점검 범위다. 실제 사건 설명·유료 모델 호출·SDP 실연결·자동 차단은 확인하지 못했다. 19단계 실집행도 별도 확인이 필요하다.
4. **포장 의도적으로 미실행:** 이번 작전은 소스 폴더 실행이다. `npm run package-app`을 실행하지 않으며, 실행형 패키지·바로가기 설치 성공이라고 하지 않는다.
5. **독립 시연·공식 합격 미확인:** 다른 사람이 화면을 직접 시연한 기록, 7일차 공식 접수/통과, 운영 인증 또는 v1.0 출시 근거가 아직 없다.

## 5. 동일 커밋을 다시 확인하는 방법 (Windows PowerShell)

기존 변경이 있는 폴더를 초기화하거나 덮어쓰지 않는다. 먼저 **GitHub 최신 내용을 받은 별도 깨끗한 폴더**의 Git 최상위에서 아래 명령을 한 줄씩 실행한다.

```powershell
git status --short
git rev-parse HEAD
cd on-client
node --version
npm run check
node tests/pc-status.test.mjs
node tests/windows-observation.test.mjs
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
```

브라우저에서 `http://127.0.0.1:5189/`을 열어 **2절 순서대로 실제로** 확인한 뒤, PowerShell 실행 창에서 `Ctrl+C`로 종료한다. 다시 실행한 결과도 별도 기록한다. **포장 명령은 실행하지 않는다.**

| 시연자가 직접 채울 기록 | 작성란 |
|---|---|
| 실측한 PC/OS와 Node 버전 | **캡처만으로 OS/Node 버전 확인 불가** |
| 시작·종료·재실행 확인 시각(KST) | **재실행 미확인**. 화면 표시 측정 시각은 E01에 별도 기록 |
| E01/E02/E03 실제 화면 관찰 결과 | **E01 제공 화면 일부 확인 / E02 미확인 / E03 일부 확인**, 위 증거표 참조 |
| 확인 불가 항목과 오류 원문/다음 행동 | Windows 기록 `확인 불가`, 로그인·기기·세션 요청 실패, 학생 영역 대기. 실행 폴더 SHA 확인 후 실패 원인을 재검증 |
| 제출용 40자리 SHA (`git rev-parse HEAD`) | **7일차 최종 커밋 후 확인** |

**학생의 시연 기록은 학생 진술이며, GitHub 원문 확인·모의 검사·실제 Windows 실행 검증·공식 AI 판정은 각각 다른 증거다.** 같은 최종 커밋의 확인 결과만 해당 버전의 결과로 묶는다.
